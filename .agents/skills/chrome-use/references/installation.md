# Install the CLI

Read this only when `chrome-devtools` is not installed or its version needs attention.

The CLI ships with the `chrome-devtools-mcp` npm package and requires Node.js/npm. Install it globally, then verify the executable:

```powershell
npm install --global chrome-devtools-mcp@latest
chrome-devtools --version
```

If `npm` is not installed, prefer installing Node.js via `scoop install nodejs`
